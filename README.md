# Vortex TV OS

Projeto de sistema Android TV minimalista para MXQ PRO 4K 5G (R329Q_V8.0 / RK322x).

**Estado:** desenvolvimento experimental. Ainda não existe firmware compilado ou imagem segura para gravação.

A implementação inicial da Build 01 ficará em uma branch própria até que existam testes suficientes. Não usar GitHub Actions; testes locais e independentes.
